# Покровский психоневрологический интернат (СПССУ)

Интерактивная презентация проекта перехода от общего больничного содержания к двухуровневой модели ухода (10 жилых домов по 6 человек + круглосуточный стационар для 40 пациентов) в с. Семетей, Манасский район, Таласская область.

## Разделы сайта
- Обзор и основные показатели проекта
- Новая схема распределения зданий и подопечных (`Было → Стало`)
- Интерактивный генеральный план 1:1000 по границам техпаспорта БТИ
- Интерактивный 3D-тур (WebGL / Three.js) по типовому дому `95,0 м²` и первым этажам Блоков 1 и 2
- Поэтажные планировки и спецификации помещений
- Расчёт штатного расписания и ведомость строений (Таблица №2 БТИ)
- План запуска на 12 месяцев
