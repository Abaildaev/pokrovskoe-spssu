# Покровский СПССУ — концепция нового формата

Страница-концепция для Министерства труда, социального обеспечения и миграции КР: стационар на 40 мест для тех, кому нужен постоянный уход, и 10 малых домов по 6 человек (60 мест) для тех, кто может жить самостоятельно. Пилотная площадка: Покровский СПССУ, с. Семетей, Манасский район, Таласская область.

Страница читается сверху вниз как документ: всё содержимое видно без вкладок и переключателей, на телефоне таблицы перестраиваются в карточки.

## Разделы
1. Зачем менять формат
2. Как устроен формат
3. Кто живёт в малых домах
4. Обычный день в доме
5. Территория (схема по техпаспорту БТИ)
6. Малый дом (3D-модель, план, комнаты, визуализации)
7. Безопасность
8. Порядок запуска
9. Что нужно от министерства
- Приложения: штатное расписание, здания по техпаспорту БТИ

## Файлы
- `index.html`, `styles/main.css` — страница и оформление.
- `scripts/house3d.js` — 3D-модель дома (Three.js загружается из `scripts/vendor/three.min.js`, только когда блок близко к экрану).
- `assets/images/genplan.svg`, `assets/images/house-plan.svg` — схема территории и план дома.
